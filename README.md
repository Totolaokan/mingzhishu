# 命之书 · 首版

写下（或说出）此刻的困惑，点「开启」，得到一句为你而写的话。
不是聊天机器人：不追问、不展示分析、不列建议；不抽签，也没有句库。

## 快速运行

需要 Node.js ≥ 22.9，无第三方依赖，不需要 `npm install`。

```bash
cp .env.example .env      # 填写模型与语音配置（可先不填）
npm start                 # 打开 http://127.0.0.1:8787
```

不填任何配置也能启动：页面会明确显示「模型尚未接入」「语音转写尚未接入」，点击开启会得到诚实的未配置提示，**不会**用预设句子代替。唯一的例外是危机表达：即使模型未配置，也会显示固定的安全支持信息，并标明「不是模型生成的回应」。

## 需要的环境变量

| 变量 | 必填 | 说明 |
|---|---|---|
| `LLM_PROVIDER` | 是 | `openai_compatible`（调用 `{BASE}/chat/completions`）或 `anthropic`（调用 `{BASE}/v1/messages`） |
| `LLM_BASE_URL` | 是 | 例如 `https://api.xxx.com/v1`；anthropic 填到域名即可 |
| `LLM_API_KEY` | 是 | 只在服务端读取，不会下发到网页（有测试验证） |
| `LLM_MODEL` | 是 | 模型名 |
| `LLM_VENDOR_LABEL` | 建议 | 显示在「发送前说明」里的服务名称；未填时显示「供应商尚未确定」 |
| `STT_BASE_URL` / `STT_API_KEY` / `STT_MODEL` | 语音必填 | OpenAI 兼容的 `/audio/transcriptions` 接口 |
| `STT_VENDOR_LABEL` | 建议 | 同上，用于语音说明 |

其余限流、超时、长度参数见 `.env.example`。部署在反向代理之后时设 `TRUST_PROXY=1`。

## 流程与设计要点

**一次开启**：`POST /api/reveal` → 服务端清洗输入（纯文本、去控制字符、≤1000 字）→ 限流与同源并发锁 → 调用模型 → 检查输出 → 不合格时带着检查结论重新生成**一次** → 仍不合格则返回 422，前端诚实提示「这一次没能写出合适的话」。

**模型输出约定**：模型只输出 `{"mode","anchor","sentence"}`。`anchor` 是从用户原话中逐字摘出的依据片段，服务端核对它确实出现在原文里（检查「有依据」），不展示给用户。不要求、也不保存任何推理过程。

**输出检查**（`server/validate.js`）：唯一 JSON、无换行/多段、只有一个句子、中文、≤90 字（20–60 字为提示词中的软参考）；拒绝说教命令、泛泛安慰、诊断、编造经历、揣定他人心意、替人裁决、引用名言、追问、标题、列表、链接。

**危机表达**：关键词保守识别 + 模型自身判断（`mode: "crisis"`）任一命中即走安全支持：允许模型写 1–3 句，并始终附上固定的安全信息（120/110、全国统一心理援助热线 12356、联系身边的人，以及非大陆地区提示）。限流、超时、模型未配置时，危机表达同样得到安全信息，而不是报错。

**超时**：单次上游 20 秒、整体 45 秒；前端 50 秒兜底。超时不自动重试，页面提供「再试一次」，文字保留。

**语音**：必须主动点击，首次录音前说明录音会交给哪个服务、本站不保存；最长 90 秒。转写文字放进书写框，提示「可能有听错」，用户修改后自己点「开启」，不会自动生成。权限被拒、浏览器不支持、转写未配置/失败/超时/为空，都有对应说明并引导文字输入，**不会伪造转写**。

**界面**：输入 → 等待 → 揭晓 / 失败四个状态，一页只显示一个；揭晓只呈现那一句话（无标题、无解释、非消息气泡）。支持手机与桌面、深色模式；Ctrl/⌘+Enter 开启，Esc 返回或取消录音，结果出现时焦点移到句子上；跟随系统「减少动效」，页内也可切换。

**隐私**：不建账号，不用 cookie/localStorage，不存历史。应用日志使用字段白名单，只记录状态码、耗时、字数区间等；上游错误响应体不读取、不记录（有测试验证日志中不出现正文、转写和输出）。页面在发送前写明内容会交给哪个服务，且明确说**无法承诺绝对私密或上游不存储**。CSP 禁止第三方资源，页面不加载外部字体或脚本。

## 测试

```bash
npm test                          # 44 项：输出检查、各场景、语音、超时、限流、日志、密钥不外泄
python3 test/browser/check.py     # 25 项：真实 Chrome 中跑界面流程，截图在 test/browser/shots/
npm run eval                      # 配置好模型后，用真实模型跑 4 个文字场景（输出只打印在终端）
```

浏览器测试需要 `pip install playwright` 和本机 Chrome（`CHROME=/path/to/chrome` 可覆盖）。
`npm test` 与浏览器测试使用**模拟上游**：它们验证的是流程、检查与界面，不代表真实模型的写作质量。

## 已知限制

- 限流与并发锁在进程内存中，只适合单进程；多实例部署需换成共享存储。
- 输出检查基于规则，可能误拒好句子，也可能放过换了说法的问题表达；上线前需要用真实模型批量人工审读。
- 危机关键词不可能穷尽，依赖模型二次判断兜底；热线信息上线前请再次核实。
- 语音需在 HTTPS 或 localhost 下使用；Safari 录制 `audio/mp4`，所选转写服务需支持该格式。
- 字体使用系统宋体栈，不同系统观感略有差异。
